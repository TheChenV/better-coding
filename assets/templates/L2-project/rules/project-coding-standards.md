# 项目编码标准

> **使用说明**：填写项目特有的编码约束。本文件补充 L0/L1 层通用规则未覆盖的项目级特殊要求。`【__名称__】` 为必填占位，`【__名称__，可选】` 为选填，`【已预填：xx，请核对】` 为 AI 预填项。

## 2. 项目特有编码约束

### 2.1 对象体系规范

| 对象类型 | 命名后缀 | 所在层 | 用途 | 转换规则 |
|----------|----------|--------|------|----------|
| 【__Entity__】 | 【__Entity__】 | 【__领域层__】 | 【__数据库映射实体__】 | 【__仅 Repository 层使用__】 |
| 【__DTO__】 | 【__DTO__】 | 【__应用层__】 | 【__服务间传输__】 | 【__Service 入参/出参__】 |
| 【__VO__】 | 【__VO__】 | 【__接入层__】 | 【__前端展示__】 | 【__Controller 出参__】 |
| 【__Request__】 | 【__Request__】 | 【__接入层__】 | 【__前端请求参数__】 | 【__Controller 入参__】 |
| 【__Command__】 | 【__Command__】 | 【__应用层__】 | 【__写操作指令__】 | 【__CQRS 写模型__】 |
| 【__Query__】 | 【__Query__】 | 【__应用层__】 | 【__读操作查询__】 | 【__CQRS 读模型__】 |

### 2.2 转换规则

- 【__Entity → DTO__】：在 【__Service 层__】 使用 【__MapStruct__】 转换
- 【__DTO → VO__】：在 【__Controller 层__】 使用 【__手动转换 / MapStruct__】
- 禁止将 【__Entity__】 直接暴露给前端
- 禁止在 【__领域层__】 使用 【__VO/Request__】 对象

### 2.3 异常处理约定

| 规则 | 说明 |
|------|------|
| 业务异常基类 | 【__BizException(code, message)__】 |
| 异常码格式 | 【__模块前缀 + 3位序号，如 USER_001__】 |
| 禁止捕获后忽略 | 【__catch 块必须有处理逻辑或重新抛出__】 |
| Controller 层 | 【__不写 try-catch，由全局异常处理器统一处理__】 |
| Service 层 | 【__抛出业务异常，不处理__】 |
| 基础设施层 | 【__捕获技术异常，转换为业务异常后抛出__】 |

### 2.4 日志规范

| 规则 | 说明 |
|------|------|
| 日志框架 | 【__SLF4J + Logback__】 |
| 日志级别使用 | 【__ERROR=系统故障, WARN=可恢复异常, INFO=关键业务节点, DEBUG=调试信息__】 |
| 必须记录 | 【__外部调用入参出参、异常堆栈、关键状态变更__】 |
| 禁止记录 | 【__用户密码、完整身份证号、银行卡号__】 |
| 格式要求 | 【__使用占位符 log.info("userId={}", id)，禁止字符串拼接__】 |

## 3. 特殊配置说明

### 3.1 多环境配置

| 环境 | 配置文件 | 用途 | 特殊说明 |
|------|----------|------|----------|
| 【__dev__】 | 【__application-dev.yml__】 | 【__本地开发__】 | 【__连接本地数据库__】 |
| 【__test__】 | 【__application-test.yml__】 | 【__测试环境__】 | 【__连接测试数据库__】 |
| 【__prod__】 | 【__application-prod.yml__】 | 【__生产环境__】 | 【__敏感配置从配置中心读取__】 |

### 3.2 配置管理规则

- 敏感配置（数据库密码、API Key）：【__使用 Nacos 配置中心 / 环境变量__】
- 功能开关：【__使用 feature.flag.xxx 格式__】
- 禁止在代码中硬编码任何环境相关配置

### 3.3 数据库规范

| 规则 | 说明 |
|------|------|
| 主键策略 | 【__雪花算法 / 自增ID__】 |
| 逻辑删除 | 【__deleted 字段：0=正常, 1=已删除__】 |
| 审计字段 | 【__created_at, updated_at, created_by, updated_by 必须存在__】 |
| 索引命名 | 【__idx_表名_字段名__】 |
| 禁止操作 | 【__禁止 SELECT *，禁止无 WHERE 的 UPDATE/DELETE__】 |
