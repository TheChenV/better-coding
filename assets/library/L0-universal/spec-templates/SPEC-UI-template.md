## 5. 交互规范

### 5.1 反馈时机

| 操作类型 | 反馈方式 | 时长 |
|---------|---------|------|
| 按钮点击 | [按钮状态变化] | 即时 |
| 表单提交 | [Loading + 成功提示] | [≤2s] |
| 删除操作 | [二次确认弹窗] | - |
| 长耗时操作 | [进度条 + 完成通知] | - |

### 5.2 动效规范

#### 动效设计原则

1. **克制**：动效用于引导注意力，不为动而动；页面 80% 交互无需动效
2. **一致性**：同类交互使用统一动效参数，禁止每种元素各一套
3. **可感知性**：动效时长 150-300ms 最佳，超过 400ms 必须可跳过
4. **性能友好**：优先使用 transform/opacity（GPU 加速），禁止动 width/height/top/left
5. **无障碍**：尊重 `prefers-reduced-motion` 系统设置，自动降级为无动效

#### 动效参数体系

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 时长-快速 | 150ms | 按钮状态、颜色变化 |
| 时长-标准 | 250ms | 弹窗、下拉、浮层 |
| 时长-慢速 | 400ms | 页面切换、大区域展开 |
| 缓动-进入 | ease-out | 元素出现（快开始慢结束） |
| 缓动-退出 | ease-in | 元素消失（慢开始快结束） |
| 缓动-强调 | cubic-bezier(0.34, 1.56, 0.64, 1) | 弹窗缩放、徽章弹出 |

#### 场景动效清单

| 场景 | 动效 | 时长 | 缓动 |
|------|------|------|------|
| 弹窗出现 | 淡入 + 缩放 (0.95→1) | 200ms | 强调缓动 |
| 弹窗消失 | 淡出 + 缩放 (1→0.95) | 150ms | ease-in |
| 页面切换 | 左右滑动 + 淡入 | 300ms | ease-out |
| 列表加载 | 逐项淡入 | 50ms/项 | ease-out |
| 卡片悬停 | 上浮 4px + 阴影加深 | 150ms | ease-out |
| 按钮点击 | 轻微缩放 (1→0.97→1) | 100ms | ease-out |
| 消息提示 | 顶部滑入/滑出 | 200ms | ease-out |
| 骨架屏 | 渐变扫光动画 | 1.5s 循环 | linear |

#### 降级策略

- `prefers-reduced-motion: reduce` 时：所有动效降级为透明度切换（≤100ms）
- 低性能设备：检测到掉帧时自动关闭非关键动效
- 离线/弱网：禁用列表逐项动画，改为一次性渲染
