# 会话上下文交接（docs/项目交接.md）

## 核心理念

> **长会话必然衰减，交接比硬撑便宜。**
> 上下文窗口是有限资源：主题数 >3、轮次 >15-20、当前主题占比 <30% 时，继续硬撑的返工成本远高于一次交接。
> 来源：mattpocock /context-handoff — 让另一个会话（或另一个 agent）拿着任务单就能接着干。
> v9.0.0 起交接面独立成文件：写入 `docs/项目交接.md`（ai 语义，手工修正保留）。手册 `docs/PROJECT-LIVE.md` 只承载提示词与进度，不再兼作交接分区——两处各写一份就是第二事实源。

## 触发条件

- 用户输入 `/context-handoff`
- 会话出现衰减信号：重复行为、方案锚定、回答变泛、跨会话上下文不一致
- 调试超过 2 小时无进展（配合 systematic-debugging 熔断）
- 任务跨天/需要换人/换环境继续

## 执行步骤

### Step 1: 盘点当前状态

收集（全部来自真实产物，禁止编造）：
1. 当前任务目标与验收标准（来自用户指令/Spec/task 清单）
2. 已完成的工作（git status/diff、已落盘文件、已通过的验证）
3. 已做出的决策及理由（含被否决的方案——防止下一会话重走弯路）
4. 未决问题与阻塞项
5. 关键文件清单（任务相关的代码/文档/配置路径）

### Step 2: 刷新 docs/项目交接.md

**写入位置**：`docs/项目交接.md`，覆盖式更新 `<!-- harness:section context ai -->` 与结束标记之间的内容（**标记本身不得改动或删除**；该文件为 ai 语义，手工修正保留、再生成时合并而非丢弃）。

**降级条款**：若项目既无 `docs/项目交接.md` 也无 `docs/PROJECT-LIVE.md`（v6 之前的旧项目）→ 退回生成 `docs/CONTEXT.md`（结构与下方模板一致），并在输出中建议升级到当前版本。

**分区内容模板：**

```markdown
> 最后交接: {YYYY-MM-DD HH:mm} ｜ 交接原因: {衰减信号/跨天/换人}

**1. 任务目标**
- 目标: {一句话}
- 验收标准: {可验证的条件}
- 关联 Spec: {docs/spec/... 路径}

**2. 已完成**
- {完成项 1，附证据（提交号/文件/测试输出）}

**3. 已决策（含否决项）**
| 决策 | 结论 | 理由 | 否决的替代方案 |
|------|------|------|----------------|

**4. 未决问题**
- {问题 1，标注阻塞/非阻塞}

**5. 下一步（按顺序）**
1. {精确到文件与操作的下一步}

**6. 关键文件清单**
- {路径: 用途}

**7. 环境备忘**
- 技术栈/启动命令/测试命令（从 AGENTS.md 摘录）
```

### Step 3: 验证交接质量

自检清单（交接内容必须让"零上下文的接手者"可执行）：
- [ ] 下一步精确到文件与操作（非"继续开发"式模糊描述）
- [ ] 已决策表包含被否决方案（防锚定）
- [ ] 关键文件路径全部真实存在（逐一 Test-Path 验证）
- [ ] 验收标准可机器验证
- [ ] 交接文件的分区标记完整无损（`<!-- harness:section context ai -->` 与结束标记成对）

### Step 4: 提示开新会话

输出交接完成提示："已刷新 docs/项目交接.md，请开新会话并让其先阅读该文件延续任务。"
（新会话由 session-start-context hook 自动探测 `docs/项目交接.md` 与 `docs/PROJECT-LIVE.md` 并提示加载；进展与下一步也可看手册顶部进度表。）

## 输出物

- docs/项目交接.md（交接内容；旧项目降级为 docs/CONTEXT.md）
- 交接质量自检结果

## 失败处理

| 失败场景 | 处理方式 |
|----------|----------|
| 任务目标无法清晰表述 | 说明交接条件不成熟，先让用户补充目标定义 |
| 关键文件清单含不存在路径 | 从清单移除并标注，禁止写入虚假路径 |
| 未决问题全部阻塞 | 在文件顶部显著标注"当前完全阻塞"，列出需要的人工输入 |
| 无 docs/项目交接.md 且无 PROJECT-LIVE.md（v6 前旧项目） | 按降级条款生成 docs/CONTEXT.md，并提示升级 |
