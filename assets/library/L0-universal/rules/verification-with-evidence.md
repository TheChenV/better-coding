# 证据驱动完成

> 来源：Superpowers verification-before-completion（680K+ 安装量）— 没有证据，就不能宣称完成。

## 强制规则

1. **宣称"完成"必须附带验证证据** — 测试输出、编译日志、命令结果
2. **无证据的完成声明无效** — "应该没问题"不是证据
3. **证据必须来自实际执行** — 不能编造或模拟证据
4. **每层完成后必须有编译+测试证据** — 再进入下一层

## 有效证据类型

| 证据类型 | 要求 |
|---------|------|
| 编译输出 | 完整的编译命令 + 输出（零 Error） |
| 测试输出 | 完整的测试命令 + 输出（通过/失败数量） |
| 命令结果 | 实际执行的命令 + 输出截图/日志 |
| 手动验证 | curl/Postman/浏览器操作 + 结果 |

## 无效证据

- "我检查过了" — 不是证据
- "代码看起来正确" — 不是证据
- 截断的输出 — 必须完整
- 模拟的输出 — 必须来自实际执行

## 违规处理

- 无证据宣称完成 → 返回执行验证，补充证据
- 伪造证据 → 严重违规，必须重新执行
