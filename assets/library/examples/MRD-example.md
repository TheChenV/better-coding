# 示例 · MRD（市场需求文档）

> 模板：`../L0-universal/spec-templates/MRD-template.md`
> 落盘：`docs/prd/MRD-MP-01.md` ｜ 产出：环节 1 `/create-proposal` 步骤 1

## 为什么这份长这样

MRD 只回答「为谁做、为什么现在做、期望什么商业结果」。
出现 P99、QPS 精确值、表结构、模块拆分就是越界——那些归 ARCH。
反过来，目标一旦不量化，下游就没有判达标的尺子。

## 章节骨架

```
文档头（编号 / 版本 / 状态 / 定位 / 边界声明 / 统一 MRD 原则）
MRD vs PRD vs SPEC 责任矩阵
1 背景与战略对齐      1.1 业务背景 1.2 战略对齐 1.3 问题陈述
2 市场机会分析        2.1 市场规模(TAM/SAM/SOM) 2.2 竞争分析 2.3 趋势
3 目标用户            3.1 画像（≥2 个）3.2 用户旅程
4 方案方向            4.1 概述 4.2 核心能力 4.3 方案边界 4.4 能力域对称契约
5 商业目标            5.1 成功指标（≥3 条量化）5.2 投资回报
6 约束与风险          6.1 约束 6.2 风险（概率×影响×处置方向）
7 利益相关者与决策机制 7.1 清单（RACI）7.2 决策机制
8 多专家并行评审记录   8.1 配置 8.2 各视角关键结论（必须留痕）
```

多应用项目只写**一份**统一 MRD，按应用拆 PRD。

## 片段 1 · 5.1 成功指标：每条都带衡量方式

```markdown
| 编号 | 目标 | 成功指标 | 怎么量 | 达成时间 |
|------|------|---------|--------|---------|
| BG-01 | 商业模型验证 | 入驻商家 ≥ 80 家 | 注册后完成首单的商家数 | 一期上线后 90 天 |
| BG-02 | 交易闭环验证 | 下单→支付成功率 ≥ 96% | 订单状态流转漏斗 | 持续 |
| BG-03 | 支付体验底线 | 支付回调成功率 ≥ 99% | 渠道回调对账 | 持续 |
| BG-04 | 用户粘性 | 30 日留存 ≥ 18% | 行为分析平台 | 一期后 6 个月 |
```

写法要点：指标名可核对（"体验好"不算）、有来源列、有达成时间。

## 片段 2 · 4.4 能力域对称契约：两侧命名一字不差

```markdown
Provider 声明
| 应用 | 能力域 | 描述（领域级，不到 API 级） |
|------|-------|--------------------------|
| mall-core | 商品能力 | SKU 管理 / 库存 / 分类 |
| mall-core | 优惠券能力 | 模板配置 / 发放 / 核销 |

Consumer 消费（必须与上表一字不差）
| 应用 | 能力域 | 调用场景 |
|------|-------|---------|
| shop-web | 商品能力 | 商品浏览与加购前库存校验 |
| vendor-console | 商品能力 | 商家上下架 |
| shop-web | 优惠券能力 | 领券中心、结算页核销 |

对称校验
- [x] 无孤立能力域（声明了没人消费）
- [x] 无幽灵引用（消费了但无人声明）
```

「商品能力」与「商品中心」两种写法同时出现 = 契约不对称，当场改名。

## 片段 3 · 6.2 风险：处置写到方向，不写口号

```markdown
| 编号 | 风险 | 概率 | 影响 | 处置方向 |
|------|------|------|------|---------|
| RISK-01 | 商家获取成本超预期，入驻数不达标 | 中 | 商业模型验证失败 | 零年费纯抽佣 + 自助导入工具，7 天上线不配专人 |
| RISK-02 | 第三方支付通道抖动 | 低 | 转化下滑 | 双通道备份 + 异步重试 + 回调对账告警 |
```

## 最容易走形的三处

1. 写了「P99 ≤ 500ms @2000QPS」——越界，改前向引用 ARCH；
   只留方向级规模（"一期峰值约 1200 QPS 量级"）。
2. 4.3 方案边界只写"包含什么"，不写"明确排除什么及原因"，
   于是二期范围一期做。
3. 第 8 章留空：多专家并行讨论过但没留痕，判据不通过。
