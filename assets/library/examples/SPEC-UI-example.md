# 示例 · SPEC-UI（UI 设计规范）

> 模板：`../L0-universal/spec-templates/SPEC-UI-template.md`
> 落盘：`docs/spec/SPEC-UI-下单与购物车.md` ｜ 产出：环节 4 `/ui-design`
> 纯后端应用：本文件位置写"跳过 + 理由"，不硬凑视觉章节。

## 为什么这份长这样

SPEC-UI 是对环节 1 已定稿原型工程的**视觉深化**，不是第二次设计：
页面结构与交互流转沿用原型，改结构要回环节 1 走 `/spec-delta`。
它值钱的地方是 Token 与四态——只有写成表，还原核对才有判据。

## 片段 2 · 2 设计 Token：可核对到像素

```markdown
#### 主色与功能色
| 名称 | 色值 | 场景 |
|------|------|------|
| Primary | #2F6FED | 主按钮、链接、选中态 |
| Primary Hover | #4B85F2 | 悬停 |
| Error | #D93B3B | 失败提示、删除类操作 |
| Warning | #E8930C | 待处理、库存紧张 |

#### 中性色（节选）
| Title #1F1F1F | 正文 #595959 | 次要 #8C8C8C | 边框 #D9D9D9 | 背景 #F5F5F5 |

#### 间距与字阶
- 间距基数 4px，只允许 4/8/12/16/24/32/48；禁止随手写 15px
- 字阶：H1 24/32/600 · H2 20/28/600 · Body 14/22/400 · Caption 12/20/400
```

## 最容易走形的三处

1. 在本文档里加了一页原型没有的"优惠券详情" → 结构变更，须回环节 1。
2. Token 只给主色，不给中性色与间距基数 → 还原时每处各自猜。
3. 漏 Error / Empty 两态，或动效只写"有过渡"不给时长与缓动。
